# Onboarding knowledge base

Fictional onboarding documents that the joiner assistant answers from. **Everything here is synthetic**, written for the LaunchPad prototype. None of it is real Lloyds Banking Group policy.

- One topic per file. The file name (without `.md`) is the document's ID, which the assistant cites.
- The first `# Heading` is the title shown to joiners.
- Edit freely: the server reads these files when it starts, so restart it to pick up changes (`npm run dev` does this automatically).
- This README is not loaded.
